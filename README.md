# 🏎️ AJITH KUMAR RACING (AKR) — OFFICIAL MOTORSPORT PLATFORM

> **RACING. PERFORMANCE. PRECISION.**
> 
> A tier-1, luxury international motorsport platform engineered for **Ajith Kumar Racing (AKR)**. Built with high-octane editorial storytelling, 360° interactive vehicle telemetry inspection, real-time Virtual Pit Wall streaming, CFD aerodynamic simulation, and an official merchandise ecosystem.

---

## 🌟 Highlights & Features

- **🏎️ Cinematic Intro & Preloader:** Laser racing line acceleration, motion-blur AKR emblem reveal, telemetry counter, and Web Audio API synthesized engine tones.
- **🎮 Interactive 360° Vehicle Viewer (`/cars`):** Rotate the **AKR GT3-01 SPEC** (510 BHP / 4.0L Flat-6) with 6 annotated hotspots for Aerodynamics, Powertrain, Brembo Brakes, KW Suspension, Carbon Cockpit, and Motec Telemetry.
- **📊 Real-Time Virtual Pit Wall (`/live`):** Live telemetry HUD with track position (**P2**), lap countdown (**84/250**), sector deltas (Purple S1 benchmark), G-Force traction friction circle (up to 4.0G), pedal load gauges, and tire/brake thermal management heatmaps.
- **💨 CFD Digital Wind Tunnel (`/technology`):** Real-time HTML5 Canvas particle stream airflow simulator with downforce vector analysis and airspeed sliders (100–320 km/h).
- **🏆 Driver Profile & Career Pedigree (`/driver`):** Complete verified record of **Ajith Kumar** with interactive timeline spanning Formula BMW (2002), British Formula 3 podiums (2004), FIA Formula Two (2010), and 24H Series Middle East & European victories (2025–2026).
- **🛍️ Official AKR Merchandise Store (`/shop` & `/checkout`):** Team softshell jackets, limited edition carbon caps (#9), telemetry tees, and 1:18 die-cast models with cart drawer and simulated instant checkout.
- **🛡️ Race Director Admin Control Room (`/admin`):** Complete CMS for publishing news dispatches, managing calendar rounds, fleet specifications, customer orders, and incoming inquiries.

---

## 🛠️ Technology Stack

- **Frontend:** React 18, Vite, Tailwind CSS, Framer Motion, GSAP, Lenis Smooth Scroll, Canvas, Lucide Icons, Web Audio API.
- **Backend:** Node.js, Express.js, Mongoose, JWT Auth, Helmet, Rate Limiting, Hybrid In-Memory Data Store.
- **Architecture:** `Frontend → API Client → Express Controllers → Data Services → MongoDB / High-Speed Engine`

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Both Frontend & Backend Concurrently
```bash
npm run dev
```

- **Frontend Application:** `http://localhost:3000`
- **Backend REST API:** `http://localhost:5000`
- **Race Director Portal:** `http://localhost:3000/admin` *(Credentials: `admin@ajithkumarracing.com` / `akr2026`)*
