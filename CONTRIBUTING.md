# Contributing to AKR Motorsport Platform

Thank you for your interest in contributing to the Ajith Kumar Racing platform!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/akracing.com.git`
3. Install dependencies: `npm install`
4. Create a feature branch: `git checkout -b feature/your-feature`

## Development Workflow

- Run `npm run dev` to start both frontend and backend
- Frontend runs on `http://localhost:3000`
- Backend API runs on `http://localhost:5000`

## Code Style

- Use ES6+ syntax with ES modules
- Follow React hooks patterns for frontend components
- Use Tailwind CSS utility classes for styling
- Write descriptive commit messages

## Pull Request Process

1. Ensure your code builds without errors
2. Update documentation if needed
3. Submit a PR with a clear description of changes
