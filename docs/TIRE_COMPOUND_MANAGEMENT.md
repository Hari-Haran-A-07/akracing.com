# 🏎️ Tire Compound Thermal Management Handbook
## Pirelli / Michelin GT3 Slick Operational Windows

### Compound Characteristics
1. **Hard Slick (H):** Working window 90°C – 110°C. High abrasion resistance.
2. **Medium Slick (M):** Working window 85°C – 100°C. Standard race stint compound.
3. **Soft Slick (S):** Working window 80°C – 95°C. Qualifying flying lap optimization.
4. **Intermediate (I):** Crossover at 1.2mm standing water. Max dry speed 220 km/h.
