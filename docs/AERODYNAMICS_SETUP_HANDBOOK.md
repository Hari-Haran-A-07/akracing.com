# 💨 Aerodynamics Calibration & Wing Setup Handbook
## AKR GT3-01 SPEC Aero Tuning

### 1. Front Splitter Wickerbills
- 5mm wickerbill provides an extra **22kg of downforce** at 240 km/h with 4kg drag penalty.

### 2. Rear Wing Angle of Attack (AoA)
- **High Downforce (Monaco / Sepang):** 11.5°
- **Medium Downforce (Dubai Autodrome / Silverstone):** 8.0°
- **Low Downforce / High Speed (Monza / Spa):** 4.5°
